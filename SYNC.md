# Sync log

Generated by the KnowledgeNetwork Design System design project.
One-way: design system → this repo → the app.

## 2026-08-05 — initial export

First full export. Contains 8 token files flattened into two stylesheets, a
Tailwind v4 theme, the scrollbar script, and the contracts for 19 components
across 5 areas (chrome, sidebar, graph, nav, doc).

Recent design system changes carried in this export:

- `--border-hair` raised to 17% bark and `--border-rule` to 25% (from 9% / 15%
  originally). At the original alphas the dividers all but vanished on paper.
- `--ring-linked` thinned to 1.5px, and it now sits over the chip's own
  `--lift-1` rather than replacing it. A chip that swaps elevation for a 2px
  ring reads as *selected*, which is a different claim.
- Relation dashes are drawn as an SVG `rect` with `shape-rendering="crispEdges"`
  (`EdgeDash`). As 3px CSS boxes they landed on different subpixel offsets down
  a list and some read visibly thicker than their neighbours.
- Scrollbar arrowheads stroke at `#c8bfaf` — `--bark-300` nudged 30% toward
  `--bark-400`, hard-coded because a `data:` URL can't read a custom property.
  Re-derive it if either bark step ever changes.
