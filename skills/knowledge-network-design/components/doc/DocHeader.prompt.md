One-line: the head of a node's document — eyebrow, domain-coloured title, ancestry.

```jsx
<DocHeader kind="topic" title="TCP & UDP" domain="net" ancestry="Computer Science / Networking / Protocol Stack" />
```

The eyebrow is the only uppercase text in the system.

**Three kinds, not three sizes.** `kind` is a *category* — one of a closed set, uppercase `--fs-micro` with `--ls-eyebrow`, and the only uppercase type in the app. `title` is a *name* — verbatim from the corpus, never re-cased or re-worded, carrying the domain hue. `ancestry` is a *location* — the full path root-first joined with `/`, never shortened to the immediate parent. All three name something real, so all three sit at `--text-2` or darker; `--text-3` is reserved for the app's own hints and empty states.
